Website portofolio pribadi **Ester Numbre** — Junior Web Developer, Vibe Coding Trainer & Designer dari Jayapura, Papua.

🔗 **Live Website:** [https://esternumbre.github.io/](https://esternumbre.github.io/)

## Tentang

Website ini adalah portofolio digital satu halaman (*single-page*) yang menampilkan profil, keahlian, proyek, dan informasi kontak Ester Numbre. Dibangun sepenuhnya dengan teknik **Vibe Coding** — pendekatan pengembangan web yang menggabungkan kreativitas, eksplorasi AI, dan coding secara intuitif.

## Teknologi yang Digunakan

- **HTML5** — Struktur semantik halaman web
- **CSS3** — Styling kustom dengan CSS variables, animasi, dan responsive design
- **JavaScript** (Vanilla) — Interaktivitas seperti navigasi, scroll animation, dan loading spinner
- **Tailwind CSS** (CDN) — Utility-first CSS framework untuk layout dan styling cepat
- **Font Awesome 6.5** — Ikon-ikon UI
- **Google Fonts** — Tipografi menggunakan *DM Serif Display* dan *DM Sans*
- **GitHub Pages** — Hosting statis gratis

## Fitur

- Desain responsif (mobile-first)
- Navigasi satu halaman dengan scroll halus
- Loading spinner animasi
- Efek fade-in saat scroll (Intersection Observer)
- Tema gelap & terang pada setiap section
- SEO-friendly dengan meta tags, Open Graph, Twitter Cards, dan JSON-LD structured data
- Tombol floating (Back to Top & GitHub)
